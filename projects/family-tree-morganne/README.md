# Morganne Shorts — Family tree

Interactive family tree (Share view) focused on **morganne**.

## Open

1. Visit this folder on GitHub Pages.
2. Enter password: `Parsons` (soft gate — family sharing only).
3. Tree loads with morganne as Primary.

Works offline in the browser after first load (uses embedded `people-data.js` + local media).
