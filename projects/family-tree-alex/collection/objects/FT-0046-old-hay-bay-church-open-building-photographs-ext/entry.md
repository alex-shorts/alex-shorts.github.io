## Visible text / architecture notes

- Two-storey box meeting house, gable roof, regular multi-pane windows — matches Parks Canada / HistoricPlaces character-defining description (companion FT-0047).
- No readable individual name plaques or Augustus Shorts inscriptions in these open exteriors.
- Historic AO titles use “Wesleyan” / “U.E.L. Missionary Methodist” — later denominational labels on the same 1792 Adolphustown building.
