# Alexander Shorts — Family tree

Interactive family tree (Share view) focused on **alexander**.

## Open

1. Visit this folder on GitHub Pages.
2. Enter password: `Shorts` (soft gate — family sharing only).
3. Tree loads with alexander as Primary.

Works offline in the browser after first load (uses embedded `people-data.js` + local media).
